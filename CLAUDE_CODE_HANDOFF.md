# Handoff для Claude Code

Этот проект уже собран. Ниже — что скормить Claude Code и что он должен сделать.
**Не нужно давать ему транскрипт переписки** — достаточно этой папки и промпта.

## Как передать Claude Code

1. Распакуйте архив, откройте папку проекта в терминале:
   ```bash
   cd ai-security-stack
   claude            # запустить Claude Code в этой директории
   ```
2. Вставьте промпт из блока ниже.

## Промпт для Claude Code

```
Это готовый проект AI-SEC — тренировочный полигон: пентест-оркестратор
(ходит в Ollama напрямую) + веб-панель + уязвимые мишени. Прочитай README.md и
LAB.md, чтобы понять структуру. Задачи:

1. Проверь целостность: все Dockerfile, docker-compose*.yml и python-модули
   на месте, синтаксис корректен, импорты сходятся.
2. Убедись, что .env НЕ отслеживается git (должен быть только .env.example).
3. Создай на моём GitHub приватный репозиторий "ai-security-stack" и запушь туда
   текущее состояние (используй мой gh CLI / настроенные креды).
4. Добавь короткое описание репозитория и топики: security, pentest, llm, ai-security.
5. НЕ меняй логику предохранителей (scope, allowlist инструментов, human-in-the-loop,
   аудит) — они намеренны.

Если чего-то не хватает для пуша (например, не настроен gh auth) — скажи, какие
команды выполнить мне, вместо того чтобы гадать.
```

## Если хотите запушить сами (без Claude Code)

Локальный git-репозиторий уже инициализирован и закоммичен. Осталось:

```bash
# 1. создать пустой репозиторий на GitHub (через сайт или gh):
gh repo create ai-security-stack --private --source=. --remote=origin --push

#   ИЛИ вручную, если репозиторий уже создан на сайте:
git remote add origin git@github.com:<ваш-логин>/ai-security-stack.git
git branch -M main
git push -u origin main
```

## Перед первым пушем — проверьте

- [ ] `.env` отсутствует в `git status` (в индексе только `.env.example`).
- [ ] в истории нет реальных токенов/ключей (`git log -p | grep -i token`).
- [ ] боевой `engagement.yml` не содержит реального scope заказчика
      (для публичного репозитория оставьте только пример-заглушку).
